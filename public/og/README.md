# Open Graph default image

Add **`default.png`** here (recommended **1200×630** px) for social previews.

Referenced by `NEXT_PUBLIC_DEFAULT_OG_IMAGE` (default: `/og/default.png`) and root metadata in `src/lib/seo/metadata.ts`.

Per-page overrides: `openGraph.image` in `src/lib/seo/pageSeo.ts` or `buildPageMetadata({ ... })`.
